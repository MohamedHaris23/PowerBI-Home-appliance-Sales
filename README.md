# Home Appliance Sale Analysis(Power BI)

## Project Overview
* An end-to-end PowerBi report to analyse and evaluate home appliance sales,customers and orders.

## Tools & Technologies
* Application: Power Bi
* Data Modelling & Calculation: DAX Measure and Relationship.

## Key Business Insights
* Metrics-- Tracked total sales, total orders nad average orders value.
* Regional performance-- Analyze map and segment visually for high performing geographic market sales.
* Filtering-- Filtering Specific product categories and time periods.
